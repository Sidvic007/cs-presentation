What this module is about

Module Aims

01
🧠

Formal patterns & languages

Understand how computers formally specify patterns, recognise languages, and model computation using state machines and regular expressions.

02
⚙️

Models of computation

Explore computability and complexity — what can be computed, how efficiently, and where the fundamental limits of computing lie.

03
🔐

Boolean algebra & cryptography

Build a solid foundation in Boolean logic and understand how modern cryptography keeps data secure in the real world.

By the end of this module

What you'll be able to do

LO 1

Boolean logic, sets & data modelling

Use Boolean logic, set theory, and set operations as tools to model data — applying them to real problems like database queries, logic gates, and filtering systems.

LO 2

Cryptography & data security

Analyse how cryptographic techniques — including hashing, digital signatures, and public key infrastructure — protect data in transit and at rest.

LO 3

Storage, processing & computation

Examine how data is physically stored and processed in computer systems — from binary encoding, CPU architectures and databases, through to algorithmic complexity and the fundamental limits of what computers can compute.
